======================================================================
                  INSTITUTION API DOCUMENTATION
======================================================================

Base URL: http://127.0.0.1:8000/
Authentication: None (Public)
Default Request Header:
  Accept: application/json

----------------------------------------------------------------------
1. ABOUT ENDPOINT
----------------------------------------------------------------------
Description: Retrieves general institutional details and primary services.

URL: /about/
HTTP Method: GET
Headers:
  Accept: application/json

Response (200 OK):
{
    "institution": "Luminartechnolab",
    "service": "software development training"
}


----------------------------------------------------------------------
2. COURSES ENDPOINT
----------------------------------------------------------------------
Description: Retrieves the list of available training programs.

URL: /courses/
HTTP Method: GET
Headers:
  Accept: application/json

Response (200 OK):
[

        "id": 1,
        "title": "Python Full Stack Development",
        "duration": "5 Months",
